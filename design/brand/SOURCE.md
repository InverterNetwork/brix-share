# Brand source

Copied on 2026-10-09 from the Brix Design System (Brix's internal design system).

Files:
- `colors_and_type.css`: tokens and semantic classes. Modified: Google Fonts import removed; type changed to match the Brix consumer app (Archivo for text, Space Grotesk for headings), with DM Mono for links, passphrases and timestamps. The font files live in `web/src/assets/fonts` (SIL Open Font License, see `LICENSE.md` there).
- `assets/logo-mark.svg`, `assets/logo-lockup.svg`: from the design system. White or black only, never orange.

The Brix name, logos and other brand assets are not covered by the repository licence; see the README.
